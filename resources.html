Resources

With this page I hope to share some of the free resources I've gathered for statistics and informatics applied to astronomy.

Statistics

  • Introduction to Probability, Statistics, and Random Processes by Hossein Pishro-Nik.
  • Seeing Theory. A visual introduction to probability and statistics.

Programming

  • Software Carpentry Lessons. Lessons on Bash, Git, Python and SQL.
  • Data Carpentry. Foundations of Astronomical Data Science.
  • Cisco Networking Academy. Lessons on C/C++, data analysis and much more.
  • freeCodeCamp. Lessons on machine learning and much more.

AI

  • 10-202: Introduction to Modern AI. A full technical course on modern artificial intelligence.
  • Claude Academy. Best practices for using AI in your projects.

Tools

  • Notion for note taking and organization. Free for students.
  • Zotero for bibliography management.
  • Visual Studio Code for coding.
  • Benty Fields to find new papers.
  • Focus Friends for a pomodoro timer.

Miscellaneous

  • Astrostatistics and Machine Learning class for the MSc degree in Astrophysics at the University of Milan-Bicocca by Davide Gerosa. This course includes both statistics and programming applied to astronomy. Can be a bit daunting for a beginner.
  • Astrophysics glossary.
  • Astronomy as a Field: A Guide for Aspiring Astrophysicists.
